# Sprint 5

Aplicativo web para análise exploratória de anúncios de veículos usados.

Este projeto usa Streamlit e Plotly Express para permitir a visualização interativa de dados de veículos, facilitando a compreensão de padrões como odômetro, preço e distribuição dos modelos disponíveis.

## Funcionalidades

- Visualização de histogramas para a coluna de odômetro
- Geração de gráfico de dispersão entre odômetro e preço
- Interface interativa com botões para criar os gráficos em poucos cliques
- Exploração rápida dos dados de veículos usados em um ambiente web simples e acessível
